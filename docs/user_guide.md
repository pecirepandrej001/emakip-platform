# EMAKIP User Guide

1. Sign in or create an account.
2. Open **Knowledge Base** and upload PDF, DOCX, TXT or Markdown documents.
3. Wait until document status becomes `ready`.
4. Open **Enterprise Chat** and ask a question about the uploaded content.
5. Expand **Sources** to inspect the retrieved evidence.
6. Open **Analytics & Reports** for platform counts.
7. Open **MLOps & System Status** for agent availability.

Agent execution panels show high-level status events only; private reasoning is not exposed.
